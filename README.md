# practice

Учебный репозиторий для конвейера `/cloud`.

## Что здесь

`pricing/` — расчёт итоговой суммы заказа. Порядок операций зафиксирован:

1. сумма позиций (`subtotal`)
2. скидка клиента (`discount_rate`) — промокод и тир лояльности **суммируются**
3. налог `TAX_RATE`
4. округление до копеек — **ровно один раз, в самом конце**

## Гарантии, на которые опираются вызывающие

- Скидка клиента применяется к сумме заказа **один раз**. Промокод и тир
  лояльности складываются в одну ставку, а не умножаются последовательно.
- `order_total` возвращает `Decimal` с двумя знаками.
- Пустая корзина даёт `0.00` при любых скидках.
